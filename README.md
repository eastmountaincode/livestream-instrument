# Cicada

Cicada is a browser-based instrument that uses environmental audio as raw material, surfacing pitches already present in live streams from the Locus Sonus project.

Resonance is a global performance control in the Track Mixer. The modulation wheel (MIDI CC1) sweeps every track from 0 (broad, Q=1) to 1 (sharp, Q=100), including held notes and harmonic bands. The on-screen slider follows the wheel and can also be adjusted directly. Pitch bend keeps its existing function.

The global resonance is saved between visits, works while the mixer is collapsed, and applies to newly connected tracks. Older sessions start from the first active track's saved resonance; each track retains its existing Level Match reference and volume.
